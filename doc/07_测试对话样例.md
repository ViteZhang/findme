# 测试对话样例：AI 自我探索教练

> 版本：v0.5 ｜ 日期：2026-11-24（v0.2：标注各样例在 V0.5 中是否适用；v0.3：多类型线索拆分、补算弱证据；v0.4：优势须有本人经历证据、他人未提及不算反证；v0.5：同步规则 R1–R7，新增 E7–E9，对齐设计稿数据）
> 配套文档：《产品方案》《技能规格说明书 v0.3》《数据模型设计 v0.2》
> 用途：用模拟对话检查各技能的流程、规则和数据写入是否顺畅，也可作为搭建 V0.5 后的验收用例。

## 使用说明

每个样例包含四部分：

| 部分 | 说明 |
|---|---|
| **场景** | 测试的技能、前置条件 |
| **对话** | 🤖 = AI 教练，🙋 = 用户 |
| **📦 数据变化** | 这段对话应该写入或更新的数据（对照《数据模型设计》） |
| **✅ 检查点** | 验收时要逐条核对的规则 |

所有样例都围绕同一个虚拟用户"小 W"展开，线索会在样例之间不断积累，方便观察置信度怎样升级。

### 线索"结构化"的升级路线（贯穿全文）

| 样例 | 新增证据 | N | S | W+ | 等级 |
|---|---|---|---|---|---|
| 样例 2 | 经历（story_0001，强 1.5）+ 用户认同 | 1 | 1 | 1.5 | **中** |
| 样例 3 | 经历（story_0002，中 1.0） | 2 | 1 | 2.5 | 中 |
| 样例 7 | 能量（er_0001，弱 0.8 × 0.5 = 0.4） | 3 | 2 | 2.9 | 中（W+ 差 0.1，未到"高"） |
| 样例 8 | 他人反馈 ×2（fbr_0001、fbr_0003，各中 1.0） | 5 | 3 | 4.9 | **高** |
| 样例 9 | 测评（大五·尽责性，中 0.5） | 6 | 4 | 5.4 | 高 |
| 样例 11 | 实验（支持，强 1.8） | 7 | 5 | 7.2 | **已验证** |

> 样例 7 是个好例子：N=3、S=2 都已达标，但三条证据里有一条是弱证据，加权分 2.9 没到 3.0，所以仍停在"中"。这正是加权分门槛要拦住的情况。

## 目录

**主线样例（按使用顺序）**
1. 目标设定：第一次见面
2. 经历挖掘 · 高光模式：产生第一条线索
3. 经历挖掘 · 第二个故事：线索合并
4. 用户主动新建线索：追问例子
5. 经历挖掘 · 低谷模式：温和处理 + 安全守护关注
6. 价值观澄清：两难取舍与"说的 vs 做的"
7. 能量分析：每日打卡与周报
8. 他人反馈：解读四类结果
9. 测评解读：吻合与矛盾
10. 画像生成：过目合并 + 逐段确认
11. 行为实验：设计与复盘
12. 回访开场：衔接上次对话

**边界样例**
- E1. 回答敷衍
- E2. 用户两次否认同一线索
- E3. 用户想让 AI 直接替他做决定
- E4. 中风险信号：暂停探索
- E5. 高风险信号：立即中断
- E6. 用户上传 MBTI 结果
- E7. 两难题不给理由 / 说「都重要」
- E8. 测评对照先跳过 / 删除原文件
- E9. 暂停期间不写入证据 / 恢复探索

## 样例 1｜目标设定：第一次见面

**场景**：新用户，用户档案为空 → 主智能体路由到"目标设定"

> 🤖 你好，我是你的自我探索教练。接下来几周，我们会一起回顾你的经历、收集一些证据，最后整理出一份有依据的个人优劣势画像。每次聊 10–15 分钟就好，随时可以停。
> 先问一个问题：**是什么让你想更了解自己？**
>
> 🙋 最近工作做了三年，有点迷茫，不知道自己到底擅长什么，也不确定要不要换方向。
>
> 🤖 工作三年后停下来想这个问题，挺正常的。你说"要不要换方向"，**最近有没有一个正在纠结的具体选择？**
>
> 🙋 有个朋友邀请我去他的创业公司，我还没想好。
>
> 🤖 明白。先说清楚一点：我不会替你做"去不去"的决定，但我们一起把你自己了解清楚之后，这个选择会好做很多。
> **聊完这一轮，你最希望得到什么？** 比如：职业方向的参考 / 更理解自己的情绪和行为 / 改善人际关系 / 单纯好奇
>
> 🙋 职业方向吧。
>
> 🤖 好。**你希望我说话直接一点，还是温和一点？要不要多举例子？**
>
> 🙋 直接点，多举例子。
>
> 🤖 收到。最后说一下隐私：你讲的内容只用于帮你分析，不会拿去训练模型，你随时可以让我删掉任何一段或全部数据。
> 我总结一下：**你工作三年，想弄清自己擅长什么，眼前有一个去创业公司的机会；这一轮的目标是找到职业方向的参考；沟通上偏好直接、多举例。** 对吗？
>
> 🙋 对。

**📦 数据变化**
```
UserProfile：goal = 职业方向；current_puzzle = "要不要去朋友的创业公司"；
             life_stage = 职场中期；comm_style = {直接, 要例子}；privacy.allow_training = false
Progress：目标设定 = 完成
```

**✅ 检查点**
- [ ] 一次只问一个问题
- [ ] 不分析、不提线索
- [ ] 明确说明不替用户做"去不去"的决定
- [ ] 说明了隐私规则和删除权
- [ ] 结尾复述并得到确认
- [ ] 建议下一步 = 经历挖掘（高光模式）

## 样例 2｜经历挖掘 · 高光模式：产生第一条线索

**场景**：目标设定已完成，故事数 = 0

> 🤖 我们从开心的经历开始。**有没有哪件事，你做完觉得"这才是我"？**
>
> 🙋 大学时组织过一个 200 人的跨院系活动，挺有成就感的。
>
> 🤖 200 人不少了。**当时是什么情况？**（情境）
>
> 🙋 社团要办，但前期特别乱，好几个部门各干各的，没人统筹。
>
> 🤖 **那你在里面负责什么？**（任务）
>
> 🙋 后来大家推我做总负责人。
>
> 🤖 **你具体做了哪些事？**（行动）
>
> 🙋 先把所有要做的事列出来，画了一张流程表，按活动日期倒排，再分给各组，每周开一次短会对进度。
>
> 🤖 **结果怎么样，你自己感觉如何？**（结果）
>
> 🙋 很顺利，老师说比往年有序很多。我自己特别有成就感。
>
> 🤖 **整个过程中，哪个环节你最投入、觉得时间过得最快？**（关键追问）
>
> 🙋 其实是一开始把一团乱麻理清楚的那几天，熬夜都不觉得累。
>
> 🤖 我注意到一个可能的线索：📌 **在混乱的局面里，擅长先梳理结构再推进**。依据是你最投入的是"理清乱麻"那段，而且熬夜也不觉得累，说明这件事不只是做得好，还给你能量。**你觉得准吗？**
>
> 🙋 挺准的，我平时也喜欢列清单。

**📦 数据变化**
```
Story story_0001：mode = 高光；title = "大学组织 200 人活动"；STAR 齐全；
                  key_moment = "前期把一团乱麻理清楚"；emotion_intensity = 4
Clue clue_0001："在混乱的局面里，擅长先梳理结构再推进"
                type = 优势候选；dimension = 能力；user_stance = 认同
Evidence ev_0001：来源 = 经历；key = story:story_0001；强度 = 强（行为 + 结果 + 能量信号）
置信度：N=1，W+=1.5，用户认同且证据强度≥中 → 中（成立中）
附带信息："平时也喜欢列清单"→ 用户自述，追加 ev_0002（自述，key = self:clue_0001，0.3）
```

**✅ 检查点**
- [ ] STAR 追问 4 轮，每轮一个问题
- [ ] 用了高光模式的关键追问
- [ ] 线索用"行为 + 情境"描述，没有贴标签
- [ ] 提炼时给出依据，并请用户确认
- [ ] 同时注意到"做得好"和"有能量"两个信号（区分优势与习得技能）
- [ ] 置信度判为"中"，不是"高"
- [ ] 给用户的小发现：一句话

## 样例 3｜经历挖掘 · 第二个故事：线索合并

**场景**：已有 clue_0001（中）

> 🤖 再聊一个高光故事。**最近一两年，工作里有没有哪件事让你特别有劲？**
>
> 🙋 去年接手一个烂摊子项目，交接文档几乎没有，我花了两周把需求、接口、负责人全部重新梳理了一遍。
>
> *（STAR 追问省略）*
>
> 🤖 **哪个环节你最投入？**
>
> 🙋 画那张系统关系图的时候，画完感觉整个项目一下子"通了"。
>
> 🤖 📌 这和你上次讲的活动很像：都是接手混乱的局面，先梳理结构。**"在混乱的局面里，擅长先梳理结构再推进"这条线索已经是第 2 次出现了**，我把这个故事作为新证据加进去。
> 另外有个小细节：你两次都提到"画图/画表"。**你是不是特别习惯用可视化的方式来理清思路？**
>
> 🙋 好像是，我脑子里想不清楚的东西，一画出来就清楚了。

**📦 数据变化**
```
Story story_0002：mode = 高光；title = "接手无文档的项目"
Evidence ev_0003 → clue_0001：来源 = 经历；key = story:story_0002；强度 = 中
  （有行为和结果，但能量信号较弱）
clue_0001 置信度：N=2，S=1，W+=2.5 → 中（不变；S=1，还到不了"高"）
Clue clue_0002（新）："习惯用画图、画表的方式理清思路"
  type = 行为模式；related_clues = [{clue_0001, 包含}]；user_stance = 认同
  Evidence ev_0004：来源 = 经历；key = story:story_0002
  Evidence ev_0005：来源 = 经历；key = story:story_0001（回溯上个故事里的"流程表"细节）
  → 两个不同故事，各算 1 条：N=2，S=1 → 中
```

**✅ 检查点**
- [ ] 识别出与已有线索高度相似 → 追加证据，不新建
- [ ] 告诉用户"第 2 次出现了"
- [ ] 两个不同故事各算 1 条证据（独立性键不同）
- [ ] **只有一种来源，即使有 2 条证据也停在"中"**（S ≥ 2 才能到"高"）
- [ ] 部分相似的新发现 → 新建线索并标记"包含"关系

## 样例 4｜用户主动新建线索：追问例子

**场景**：对话中用户主动给出自我判断

> 🙋 对了，我觉得我还挺有耐心的。
>
> 🤖 记下了，📌 **"有耐心"** 先作为一条线索登记。**能讲一次你特别有耐心的经历吗？** 越具体越好。
>
> 🙋 嗯……一下子想不起来。
>
> 🤖 没关系，不用硬想。我先把它标记成"待补例子"，之后聊的时候想到了随时告诉我。

**📦 数据变化**
```
Clue clue_0003："有耐心"
  created_by = 用户；status = 待观察；needs_example = true
  Evidence ev_0006：来源 = 用户自述；权重 0.3
置信度：N=0（自述不计入 N）→ 线索
```

**分支：用户讲出了例子**
> 🙋 有了，我带过一个实习生，同一个问题他问了五遍，我每次都换个方式讲，最后他学会了。
>
> 🤖 这个例子很具体。我们展开聊聊——**当时他第几遍问的时候，你心里是什么感觉？**
> *（转入经历挖掘·日常模式）*

```
Story story_0003；Evidence ev_0007 → clue_0003：来源 = 经历
needs_example = false；N=1 → 待用户确认后可到"中"
```

**✅ 检查点**
- [ ] 先做合并检查（与已有线索不相似 → 新建）
- [ ] 登记为线索 + 自述证据，状态是"待观察"
- [ ] **当场追问一个具体例子**
- [ ] 用户想不起来时不强求，标记"待补例子"
- [ ] 讲出例子后转入经历挖掘，产生"经历"证据
- [ ] 自述证据不能单独让线索升级

## 样例 5｜经历挖掘 · 低谷模式：温和处理 + 安全守护关注

**场景**：高光故事 ≥ 3 个，低谷故事 = 0

> 🤖 前面聊了几次高光时刻，今天想换个方向，聊一段不那么顺的经历。**这部分可能会勾起一些不舒服的感受，你随时可以说"跳过"或者"今天先到这"。** 可以吗？
>
> 🙋 可以。
>
> 🤖 **有没有哪段经历，让你特别挫败，或者特别想逃开？**
>
> 🙋 第一份工作的主管，每天让我汇报三次进度，连邮件措辞都要改。那半年我特别压抑。
>
> 🤖 听起来那半年确实不好受。**最难受的是哪个点？是事情本身，还是别的什么？**
>
> 🙋 事情本身不难，难受的是感觉自己完全没有自主权，像个执行机器。
>
> 🤖 📌 我注意到两个可能相关的线索：**一是"自主权"对你很重要；二是被管得太细会明显消耗你的能量**。你觉得准吗？
>
> 🙋 准，这可能也是我考虑去创业公司的原因之一。
>
> 🤖 这个联系很有意义，我记下了。今天聊这些不轻松，谢谢你愿意说。要继续，还是先到这里？

**📦 数据变化**
```
Story story_0004：mode = 低谷；emotion_intensity = 4 → 通知安全守护关注（低风险，正常共情）
一段材料指向两种类型 → 拆成两条相关线索：
Clue clue_0004："自主权对我很重要"
  type = 价值观；related_clues = [{clue_0012, 相关}]；user_stance = 认同 → 中
Clue clue_0012："被管得过细会明显消耗我"
  type = 能量消耗；related_clues = [{clue_0004, 相关}]；user_stance = 认同 → 中
两条线索各有 1 条来自 story_0004 的证据（独立性键只在同一线索内去重）
附注：用户把线索和当前困惑联系起来 → 记入对话进度，供画像"最佳状态说明书"参考
```

**✅ 检查点**
- [ ] 开头说明可以随时跳过
- [ ] 语气比高光模式更温和，先共情再追问
- [ ] 用了低谷模式的关键追问
- [ ] 情绪强度 ≥ 4 → 通知安全守护
- [ ] 同时指向价值观和能量消耗的材料，拆成两条相关线索
- [ ] 结尾致谢并询问是否继续

## 样例 6｜价值观澄清：两难取舍与"说的 vs 做的"

**场景**：已有 4 个故事

> 🤖 这些价值观里，**挑出 10 个你最有共鸣的**：自由、成就、安全、认可、成长、关系、意义、影响力、稳定、创造……
>
> 🙋 自由、成长、成就、意义、认可、稳定、创造、关系、影响力、健康。
>
> 🤖 来几道两难题。**A：薪水高 30%，但每件事都要请示；B：薪水不变，但你可以自己决定怎么做。选哪个？**
>
> 🙋 B，毫不犹豫。
>
> 🤖 用一句话说说为什么？
>
> 🙋 被人盯着做事比少拿钱难受多了。
>
> 🤖 **A：稳定的大公司，晋升慢但可预期；B：创业公司，成长快但可能一年后倒闭。**
>
> 🙋 这个……好难。可能还是 B，但会很焦虑。
>
> 🤖 "会很焦虑"这个反应很重要，说明"稳定"对你也有分量，只是没排在最前面。
> *（继续 3–5 轮）*
>
> 🤖 有一点想和你探讨：你把"成长"排在第二，但你讲的三个高光故事里，有两个都提到"老师/领导说比往年好"。**"被认可"对你的分量，会不会比你想的更重一些？**（这不是说你说得不对，只是一个值得想想的问题。）
>
> 🙋 ……好像是。我确实挺在意别人的评价。
>
> 🤖 我们排一下最终的 Top 5，每个用一句话说说"对你来说它意味着什么"。

**📦 数据变化**
```
ValueRanking vr_0001：top5 = [自由, 成长, 认可, 成就, 稳定]（附用户定义）
  inconsistencies = ["说看重成长，但高光故事多与被认可相关"]
tradeoffs[0]：{A: 薪水高 30% 但要请示, B: 自己决定怎么做, 选择: B, 理由: "被人盯着做事比少拿钱难受多了"}
tradeoffs[1]：{选择: B, 理由: "会很焦虑"}（理由指向稳定，不作为自主权证据）
Evidence → clue_0004（自主权）：来源 = 价值观；key = values:vr_0001；excerpt = 理由原话；强度 = 中（0.8）
  clue_0004：N=2，S=2，W+=1.5+0.8=2.3 → 中（W+ 还不够 3.0）
Clue clue_0005："不一致：说看重成长，但成就感常来自被认可"
  type = 不一致 → 只在对话中探讨，不进画像
```

**✅ 检查点**
- [ ] 两难题根据用户的初选来设计
- [ ] 每道题选完都请用户用一句话说理由，理由原话写入证据（R1）
- [ ] 用户犹豫时，把犹豫本身当作信息
- [ ] 用故事验证价值观
- [ ] 不一致之处温和提出，并说明"不是说你说得不对"
- [ ] "不一致"类型线索不进画像
- [ ] 用户确认 Top 5 排序

## 样例 7｜能量分析：每日打卡与周报

**场景 A：每日打卡（1 分钟）**

> 🤖 晚上好，1 分钟打个卡 👇
> **① 今天整体能量几分？（1–10）**
>
> 🙋 7
>
> 🤖 **② 今天最让你充电的一件事？**
>
> 🙋 下午一个人把下季度的计划框架搭出来了。
>
> 🤖 **③ 最消耗你的一件事？**
>
> 🙋 上午连开了三个会。
>
> 🤖 记好了，明天见。

**场景 B：第一份周报（打卡 6 天，累计 < 14 天）**

> 🤖 这周你打卡了 6 天，先分享几个**初步观察**（数据还少，不算规律）：
> 1. 4 次"充电"都发生在**独处、做规划或梳理**的时候
> 2. 3 次"消耗"都和**连续开会**有关

> 🤖 没关系，先这样记下。

**📦 数据变化**
```
tradeoffs[n]：{稳定 vs 成长, skipped = true}（追问 2 次后跳过，不产生证据）
tradeoffs[n+1]：{选择: A, 理由: 空} → 价值观证据强度 = 弱（0.8 × 0.5 = 0.4）
```

**✅ 检查点**：「都重要」最多追问 2 次，之后允许跳过，不催促（R3）；跳过的题不产生证据；没有理由时证据记为弱（R1）；不评判用户的选择

### E8｜测评对照先跳过 / 删除原文件

> 🤖 测评说你更多从独处中恢复能量，但你做过 200 人活动的总负责人。你怎么看？
> 🙋 这个我还没想好，先跳过吧。
> 🤖 好，放到最后。下一条：测评说你喜欢新想法，我们还没聊到。你有类似的经历吗？
> *（其余对照完成）*
> 🤖 大五人格对照完了。有 1 条你先跳过了：外向性和牵头活动的那条，下次想聊随时可以。分数已经记下，原文件要保留吗？
> 🙋 保留吧。

**📦 数据变化**
```
Assessment.skipped_items = ["外向性 ↔ 牵头 200 人活动"]（不产生证据，不新建线索）
本次小结：未回应 1 条
UserProfile.privacy.keep_raw_assessment = true（下次上传不再询问）
```

**✅ 检查点**：每条对照都能「先跳过」，跳过的不产生证据（R2）；小结里列出未回应的条目；询问是否删除原文件，选择被记住（R7）

### E9｜暂停期间不写入证据 / 恢复探索

**场景 A：中风险暂停中，用户继续讲经历**

> 🙋 其实那半年我每天都在列清单，不列就睡不着。
> 🤖 听起来那段时间你一直在想办法让自己撑住。我在这里，想说什么都可以。

**📦 数据变化**：工具层拒绝 `story.create` 和 `evidence.add`；「梳理结构」等线索的证据数不变

**场景 B：第二天，用户说好多了**

> 🙋 这两天好多了，睡得也还行。想接着聊。
> 🤖 听到你好一些，我挺高兴的。我们可以接着来，也可以换个轻松一点的方向，比如先讲一个高光的事。你想怎么来？
> *（快捷回复：接着聊那位主管 / 先讲一个高光的 / 今天就随便聊聊）*

**📦 数据变化**：下一轮无风险信号 → 教练确认后 Progress.paused_by_safety = false；高风险事件需当前时间 ≥ resume_not_before

**✅ 检查点**：暂停期间的内容不变成证据（R6）；恢复必须由用户主动提出，且下一轮无风险信号；高风险后至少隔一天；恢复时不直接回到低谷话题，先给方向选择
