## 打开设计稿

- 用浏览器直接打开 HTML 文件。需要联网，字体和图标从公共 CDN 加载
- 操作方式和 Figma 类似：左侧切换页面和画板，拖动平移，Ctrl / ⌘ + 滚轮缩放，点击画板在右侧看说明
- 每个批次文件里都有「状态与交互」页和「检查清单」页
- 设计令牌是页面里的 `--page-*` CSS 变量，可以直接取用
