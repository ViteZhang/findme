## 1. 设计原则

| 原则 | 落到界面上 |
|---|---|
| **对话是主线，页面是档案** | 所有"产生证据"的动作都发生在对话里；线索、故事、画像页面只负责查看、修正和删除 |
| **任何时候都说清"还差什么"** | 不可用的按钮必须写明原因，例如"还差 3 条「高」线索"，不只是变灰 |
| **用户能推翻 AI** | 每条线索、每条证据、每段画像都有"修改 / 否认 / 删除"的入口，且不超过两次点击 |
| **离开不丢东西** | 对话随时可以离开，回来时从原处继续；没有"保存"按钮 |
| **安全优先于一切流程** | 安全提示可以出现在任何页面，并能冻结当前流程 |

## 3. 导航模型

### 3.1 桌面端

```
┌────────────┬──────────────────────────────────────┐
│ 照见        │ 标题栏（页面名 · 右侧元信息）            │
│            ├──────────────────────────────────────┤
│ 首页        │                                      │
│ 对话        │                                      │
│ 线索    5   │            内容区                     │
│ 画像  未生成 │                                      │
│ 打卡   6天  │                                      │
│            │                                      │
│ 你讲过的故事 │                                      │
│  · 最近 4 条 │                                      │
│  · 全部故事 │                                      │
│            │                                      │
│ 设置        │                                      │
│ W Wortley  │                                      │
└────────────┴──────────────────────────────────────┘
```

- 侧栏宽 248，常驻。导航项右侧的元信息是活的：线索数、画像状态、打卡天数
- "他人反馈"不在一级导航，入口在线索库和画像页（V0.5 用得少）
- 对话页打开时，侧栏保留，内容区变成对话流；右侧可展开一个 320 宽的"本次发现"面板（见 P2）

### 3.2 移动端

- 底部标签栏 4 个：首页 / 线索 / 打卡 / 画像
- **对话不占标签**：从首页输入框或任何"开始对话"按钮进入，全屏打开，左上角返回
- 故事列表、设置从首页右上角头像进入

### 3.3 返回与深链

| 从哪里 | 到哪里 | 返回到 |
|---|---|---|
| 对话里的线索卡 | 线索详情 | 对话原位置 |
| 线索详情里的证据 | 故事详情（定位到原话） | 线索详情 |
| 首页线索卡按钮 | 对话（测评解读 / 价值观） | 首页 |
| 画像里的一条结论 | 线索详情 | 画像原位置 |

## 4. 核心用户流程

每个流程标出经过的页面和状态，设计时按流程逐帧检查。

### F1 第一次使用
```
P0.1 欢迎与隐私说明 ──同意──▶ P2.1 目标设定（7 步）──确认总结──▶ P1 首页（探索中 · 0 条线索）
            └──不同意──▶ 停在 P0.1，可阅读完整隐私说明
```
关键状态：同意前不能输入；目标设定中途离开，下次打开回到 P2.1 原位置。

### F2 讲一个故事（主循环）
```
P1 首页 ──输入 / 快捷入口──▶ P2.2 经历挖掘
  ├─ 引出故事 → STAR 追问（最多 4 轮）→ 关键追问
  ├─ 线索提炼卡 ──准──────────▶ 写入，刻痕长出一笔
  │            ├─部分准 → 原地改写说法 → 写入
  │            └─不准 ──→ 追问更准确的说法（第 1 次降级 / 第 2 次归档）
  ├─ 合并检查 → 「这已经是第 2 次出现了」提示
  └─ 本次小结（新故事 1 个 · 新线索 / 新证据 N 条 · 建议下一步）
        └──▶ P1 首页（线索列表、进度已更新）
```
分支：回答敷衍 → 换问法 → 建议换故事或休息；低谷模式 → 开头提示可跳过、"跳过"常驻。

### F3 补一条外部来源（测评）
```
P1 首页线索卡「上传测评」──▶ 文件选择 ──▶ 解析中（进度 + 可离开）
  ├─ 解析失败 → 原因 + 重新上传 / 改为粘贴文字
  ├─ 识别为 MBTI → 说明不计入证据，转为追问例子
  └─ 解析成功 ──▶ P2.4 测评解读：翻译 → 吻合 / 矛盾 / 新发现 → 逐条回应
        └─ 线索升级 → 对话内升级提示 →「查看线索」/「继续」
```

### F4 价值观澄清
```
P2.3 ─ 选词（从约 30 个里选 10 个）─▶ 两难取舍 5–7 轮 ─▶ 对照故事 ─▶「说的 vs 做的」探讨（如有）─▶ 排出 Top 5 + 一句话定义 ─▶ 确认
```
特殊交互：选词网格、二选一卡片、拖拽排序（移动端用上下箭头）。中途离开保留已选。

### F5 生成画像
```
P5.1 未生成（显示门槛进度）──条件满足──▶ 「生成画像」可用
  └──▶ P5.2 ① 合并过目（逐条：对 / 拆开）
           ② 待补例子提示（可跳过）
           ③ 生成中（自检清单逐项打勾，约 30 秒）
           ④ 逐节确认（8 节，每节：准 / 改一下）
           ⑤ 定稿 → v1 → 导出（Markdown / Word）
```
关键状态：生成中离开 → 后台继续，首页显示"画像 v1 待确认"；逐节确认可以分几次完成。

### F6 每日打卡
```
提醒（系统通知，晚上，时间可设）──▶ P2.5 打卡：分数 → 充电的事 → 消耗的事 →（可选补充）──▶ 完成，记录天数 +1
```
也可以从首页打卡区直接点分数开始。连续 3 天未打卡 → 首页轻提示"要不要换个提醒时间"。

### F7 安全中断（任何对话中）
```
检测到中风险 ──▶ 对话内中风险卡片：暂停当前模块 → 求助渠道
   └─ 用户继续聊 → 正常陪伴，不恢复探索；首页显示"今天的探索已暂停"
检测到高风险 ──▶ 高风险卡片（对话内，置顶）+ 输入框上方常驻求助入口 → 不进入任何探索流程
恢复：用户主动说"我好多了 / 继续"且下一轮无风险信号 → 教练确认后恢复
```

### F8 修正 / 否认一条线索（在对话外）
```
P4.2 线索详情 ─ 改说法 → 原地编辑 → 标「你修改过」
             ─ 这不像我 → 确认弹层（说明会降一级 / 会归档）→ 降级或归档
             ─ 补一个例子 → 打开 P2.2（日常模式，带着这条线索）
             ─ 已归档 → 恢复
```

### F9 删除一个故事
```
P3.2 故事详情 ─ 删除 → 影响预览弹层（会失效的证据 N 条 · 会降级的线索列表）→ 确认 → 重新计算 → toast
```
删除不可撤销，所以必须先展示影响。

### F10 回访
```
打开 ──▶ P1 首页：开场句 = 上次停在哪里 + 最接近升级的线索 + 一个建议动作
```

## 5. 各页面详细结构与状态

格式：**结构**（从上到下的区块）→ **状态**（每个都要画）→ **交互细节**。

### P0.1 欢迎与隐私说明

- 结构：产品一句话说明 → 会怎么进行（约几周、每次 10–15 分钟）→ 隐私三条（只用于你、不训练、随时删除）→ 同意并开始 / 阅读完整说明
- 状态：默认 · 完整说明展开
- 交互：同意后直接进入 P2.1，教练第一句话已经在屏幕上

### P1 首页

- 结构：开场句（教练的话）→ 输入框 + 上次聊到 → 高光线索卡 → 全部线索（前 5）→ 探索进度 → 今天的能量
- **状态（6 个）**

| 状态 | 触发条件 | 开场句与主区域 |
|---|---|---|
| S1 新用户 | 目标设定刚完成，0 个故事 | 「从一件让你觉得"这才是我"的事开始」，无线索卡，显示 3 个故事开头示例 |
| S2 探索中 | 有线索，没有「高」 | 最接近升级的线索卡（现有设计稿） |
| S3 可以生成画像 | 「高」≥ 3 | 主操作变为「生成画像」，线索卡换成 3 条「高」线索摘要 |
| S4 画像待确认 | 生成完成，未逐节确认完 | 「画像 v1 还有 5 节等你看」，继续确认 |
| S5 已有画像 | 画像定稿 | 画像摘要 + 最近变化（新增 / 升级的线索）+ 继续探索 |
| S6 安全暂停 | 中 / 高风险未解除 | 不显示线索和进度，只显示一句关心 + 求助资源 + 输入框 |

- 交互细节
  - 开场句由主智能体生成，规则固定：上次内容 + 一个发现 + 一个建议，不超过 2 句
  - 线索卡只选 1 条：优先选"差一步就升级"的；其次选与目标最相关的
  - 打卡区：今天已打卡时显示今天的分数和"已记录"，不再显示 1–10

### P2 对话（核心）

- **整体结构**
```
┌─ 标题栏：当前模式（例：经历挖掘 · 高光）· 第几个故事 · [结束本次]
├─ 对话流
│    教练消息（无气泡）/ 你的消息 / 内联组件（线索卡、合并提示、升级提示……）
├─ 快捷回复（仅在特定时刻出现，最多 3 个）
└─ 输入框（附件 · 语音 · 发送）　　低谷模式：上方常驻「跳过这个话题」
右侧可展开：本次发现面板（本次新增的故事 / 线索 / 证据，实时更新）
```

- **通用状态**

| 状态 | 说明 |
|---|---|
| 教练正在思考 | 三道刻痕标识轻微淡入淡出，不用"打字中…"文字 |
| 等待你回答 | 输入框聚焦，必要时出现快捷回复 |
| 网络失败 | 你的消息下方「没发出去 · 重试」，内容保留 |
| 生成失败 | 教练消息位置显示「我刚才没想好，再试一次」 |
| 续聊 | 回到对话时，顶部一行「上次聊到这里」分隔线 |
| 本次结束 | 本次小结卡片 + 两个按钮：再聊一个 / 回首页 |
| 安全暂停 | 见 F7 |

- **内联组件（每个都要在设计稿里画出所有状态）**

| 组件 | 出现时机 | 状态 |
|---|---|---|
| 线索提炼卡 | 提炼出线索 | 待回应 · 已认同 · 改写中 · 已改写 · 已否认 |
| 合并提示 | 新证据并入已有线索 | 「这已经是第 N 次出现了」+ 刻痕；已确认线索：询问是否合并（合并 / 分开记） |
| 升级提示 | 线索等级变化 | 中 → 高（强调）· 降级（中性语气） |
| 本次小结 | 一个技能结束 | 新故事 · 新线索 · 新证据 · 建议下一步 |
| 中 / 高风险卡片 | 安全守护触发 | 见设计规范组件 |
| 上传卡片 | 测评上传后 | 上传中 · 解析中 · 成功 · 失败 · 不计入证据（MBTI） |

- **按模式的特殊交互**

| 模式 | 特殊交互 |
|---|---|
| P2.1 目标设定 | 「你最希望得到什么」用 4 个选项卡片 + 其他；最后的总结卡片可编辑 |
| P2.2 经历挖掘 | 模式标签可切换（高光 / 低谷 / 日常）；低谷模式常驻「跳过」 |
| P2.3 价值观澄清 | ① 选词网格（显示已选 N / 10）② 二选一卡片（选完要说一句为什么）③ 排序列表（拖拽，移动端用上下箭头）④ Top 5 每项一句定义 |
| P2.4 测评解读 | 测评摘要卡（维度 + 大白话）；吻合 / 矛盾逐条出现，每条都需要回应才能继续 |
| P2.5 能量打卡 | 1–10 分段按钮 → 两个短输入 → 完成；全程 1 分钟内 |
| P2.6 自由聊天 | 教练判断后给出 1–2 个去向建议（快捷回复形式） |

### P3 故事

- **P3.1 故事列表**：按时间倒序；每行：标题 · 模式（高光 / 低谷 / 日常）· 日期 · 产生的证据数；筛选：模式
  - 状态：空（「还没有故事，从首页开始讲第一个」）· 正常
- **P3.2 故事详情**：标题（可改）· 时间与领域 · STAR 四段 · 关键时刻 · 由这个故事产生的证据（每条链接到线索）· 删除
  - 状态：完整 · 未完成（STAR 缺项，提示「继续讲完」→ 回对话）· 删除确认

### P4 线索

- **P4.1 线索库**
  - 结构：顶部一句总结（「8 条线索，2 条到「高」」）→ 筛选（类型 · 等级 · 只看待补例子）→ 线索表（线索 · 类型 · 刻痕 · 等级）→ 已归档（折叠）
  - 状态：空 · 正常 · 筛选无结果 · 有待过目的自动合并（顶部提示条）
- **P4.2 线索详情**
  - 结构：说法（可改）+ 类型 + 等级 → 大刻痕 + 三道门槛条 → 还差什么 + 对应动作 → 证据列表（原话 · 来源 · 强度 · 链接）→ 相关线索 → 变更记录（折叠）→ 操作：改说法 / 这不像我 / 补一个例子
  - 状态：线索 · 中 · 高 · 已验证（V2）· 已归档 · 待补例子 · 你修改过 · 有反对证据（显示反对证据分组）

### P5 画像

- **P5.1 未生成**：标题「还不能生成画像」→ 三个条件的进度（「高」线索 1 / 3 · 价值观澄清 未完成 · 来源种类 1 / 2）→ 每个条件对应一个动作
- **P5.1 已生成**：版本号 · 生成日期 · 八节内容（每条结论带刻痕，可点开证据）→ 导出 · 历史版本
- **P5.2 生成流程**：4 个步骤（顶部步骤条），每步一屏
  - ① 合并过目：逐条两个按钮「对」「拆开」，全部处理完才能下一步
  - ② 待补例子：列出缺例子的线索，可「现在补」或「先跳过」
  - ③ 生成中：自检清单逐项出现（单一来源检查、措辞匹配、标签检查……）
  - ④ 逐节确认：一节一屏，「准」「改一下」；改一下 → 原地编辑，标「你修改过」
- **P5.3 历史版本**：版本列表 + 两版对比（新增 / 升级 / 降级 / 移除）
- 状态：未生成 · 生成中 · 待确认（第 n / 8 节）· 已定稿 · 生成失败

### P6 打卡记录

- 结构：累计天数（「6 / 14 天，满 14 天后 V1 会生成能量周报」）→ 日历（每天一格，按分数深浅）→ 列表（日期 · 分数 · 充电 · 消耗）
- 状态：空 · 今天未打卡 · 今天已打卡 · 连续 3 天未打卡（提示调整提醒时间）
- V0.5 不显示任何"规律"结论

### P7 他人反馈（V0.5 仅收集）

- **P7.1 准备问卷**：说明（为什么要找 5–8 人、至少 3 种关系）→ 问卷题目（可复制）→ 邀请话术（匿名 / 实名两版，可复制）
- **P7.2 导入回复**：粘贴或上传一份回复 → 选择关系 → 保存；已收到 N 份列表
- 状态：未开始 · 已收集 1–2 份（「还差 N 份才能开始分析，V1 上线解读」）· 已收集 ≥ 3 份

## 6. 全局交互规则

### 6.1 对话

| 规则 | 细节 |
|---|---|
| 发送 | Enter 发送，Shift + Enter 换行；移动端用发送键 |
| 一次一问 | 教练每条消息只有一个问题；快捷回复最多 3 个，且只在选择题时出现 |
| 打断 | 教练生成中，用户可以继续输入；发送后教练停止当前回复并回应新消息 |
| 中途离开 | 自动保存，不弹"确定离开吗" |
| 编辑已发消息 | V0.5 不支持。改说法通过线索卡和线索详情完成 |
| 语音 | 按住说话（移动端）/ 点击开始（桌面端），转成文字后可编辑再发 |

### 6.2 证据与线索的即时反馈

| 事件 | 反馈 |
|---|---|
| 新增一条证据 | 对话内刻痕长出一笔（400ms）；侧栏线索数 +1 |
| 线索升到「高」 | 对话内升级提示 + 首页下次打开时作为开场句素材 |
| 线索降级 / 归档 | 对话内中性提示，不用警示色 |
| 自动合并 | 不打断对话；线索库顶部提示条「3 处合并等你过目」 |

### 6.3 不可用与确认

| 场景 | 规则 |
|---|---|
| 按钮不可用 | 必须写原因（按钮下方一行小字，或悬停说明） |
| 可撤销操作（改说法、合并、归档） | 直接执行 + toast「已归档 · 撤销」，5 秒 |
| 不可撤销操作（删除故事、删除全部数据） | 先展示影响，再确认 |

### 6.4 文案

- 教练说话：完整句子，可以用"你""我们"；不用问候语、感叹号
- 界面标签和按钮：不加句号；动词开头（「上传测评」「生成画像」）
- 空状态：说清楚下一步，例如「还没有故事，从首页开始讲第一个」
- 数量：等宽数字，统一用「2 / 3」格式表示进度

### 6.5 响应式

| 断点 | 布局 |
|---|---|
| ≥ 1280 | 侧栏 248 + 内容区；对话页可展开右侧「本次发现」 |
| 768–1279 | 侧栏收起为图标（64），本次发现面板改为抽屉 |
| < 768 | 底部标签栏；对话全屏 |
