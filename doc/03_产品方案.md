## 1. 背景与初心

- **从自己开始**：先把自己当成第一个用户，验证出一套真正有效的自我认知方法。
- **再帮助更多人**：把验证过的方法沉淀成工具，帮助正在迷茫、转型或想更了解自己的人。
- **为什么做成 AI 产品**：自我探索需要"有人追问、有人记录、有人整理"。AI 可以长期陪伴，记住用户讲过的每个故事，并把零散的信息整合成有依据的结论。

## 2. 方法论基础："5+1" 维度框架

| 维度 | 核心问题 | 举例 |
|---|---|---|
| **1. 性格特质** | 我天生倾向怎样待人做事？ | 内向/外向、对细节和结构的偏好、情绪稳定性 |
| **2. 能力与技能** | 我擅长什么？哪些是练出来的，哪些是天赋？ | 逻辑分析、表达、组织协调、创造力 |
| **3. 价值观与动机** | 什么对我最重要？什么能驱动我？ | 自由、成就、安全感、帮助他人、认可 |
| **4. 能量模式** | 做什么让我充电，做什么让我耗竭？ | 独处思考 vs 与人互动，深度工作 vs 多线并行 |
| **5. 关系与沟通** | 别人眼中的我是怎样的？我在团队里通常是什么角色？ | 倾听者、推动者、协调者 |
| **+1. 盲点与模式** | 我反复踩的坑是什么？压力下我会变成什么样？ | 拖延、过度承诺、回避冲突 |

> 💡 **关键认识**：优势 ≠ 擅长的事。真正的优势是"做得好 + 做完有能量 + 愿意持续做"。只擅长但做完很累的，算"习得技能"，不算核心优势。

### 四种互相印证的方法

| 方法 | 方向 | 做法 |
|---|---|---|
| **自我反思** | 向内看 | 高光时刻回顾、低谷时刻回顾、每日能量日志 |
| **科学测评** | 借助工具 | 大五人格、VIA 性格优势、盖洛普优势识别、MBTI（仅供参考） |
| **他人反馈** | 向外看 | 找 5–8 个不同关系的人反馈，参考"反射最佳自我"练习和乔哈里视窗 |
| **行为实验** | 实践验证 | 针对"假设优势"刻意练习，观察结果和感受 |

> ⚠️ 单一方法容易失真，测评只是"假设"，需要与其他方法交叉验证。

## 3. 产品定位与差异化

| | 传统测评（MBTI、盖洛普） | 普通 AI 聊天 | **本产品** |
|---|---|---|---|
| 形式 | 做选择题 | 你问它答 | **AI 主动提问，一步步引导** |
| 依据 | 自我打分 | 没有结构 | **真实经历 + 测评 + 他人反馈** |
| 结果 | 一个标签 | 零散建议 | **画像随经历不断更新** |
| 记忆 | 做完就结束 | 每次从头开始 | **记得你说过的内容，长期陪伴** |

**核心竞争力**：不是提示词，而是**线索/证据库的数据模型和证据规则**，它让每条结论都可追溯、可升级、可反驳。

## 5. 核心体验：对话流程

把方法拆成多个对话模块，用户可以按顺序走，也可以随时进出：

```
① 目标设定  →  ② 高光时刻  →  ③ 低谷时刻
                                   ↓
⑥ 画像生成  ←  ⑤ 他人反馈  ←  ④ 价值观与能量
                 ↓
         ⑦ 行为实验与持续更新（长期）
```

### 对话示例（高光时刻）

> **AI**：回想一下，过去几年里有没有哪件事，你做完觉得"这才是我"？说说当时的情况。
> **用户**：大学时组织了一次 200 人的活动……
> **AI**：听起来很有成就感。当时哪个环节你最投入？是规划流程、说服别人参与，还是现场应变？
> **用户**：其实是前期把一团乱麻理清楚的那段。
> **AI**：📌 我记下了一个可能的优势线索：**"把复杂的事结构化"**。后面我们看看它会不会在别的经历里也出现。

### AI 的三个关键技巧

1. **追问细节**：用 STAR 方法（情境、任务、行动、结果）把一个故事挖深
2. **只提假设，不下结论**：每个发现先标成"线索"，有 2–3 个独立证据才升级为"优势"
3. **跨对话找规律**：例如"你第三次提到'讨厌被催'了，这可能和你很看重的'自主'有关"

## 7. 产品架构：智能体 + 技能

### 7.1 为什么不能只靠一套提示词

| 问题 | 只用一套提示词 | 智能体 + 技能 |
|---|---|---|
| **流程复杂** | 所有规则塞在一起，AI 容易顾此失彼 | 每个技能只管一件事，规则清楚，可单独调优 |
| **跨对话积累** | 每次基本从头开始 | 线索和证据存进数据库，持续积累 |
| **结构化产出** | 画像质量看 AI 当时的发挥 | 画像技能读取证据库，按固定标准生成 |
| **外部动作** | 只能聊天 | 能发问卷、解析测评报告、定时提醒 |
| **迭代** | 改一处可能影响全局 | 单独升级某个技能，不影响其他部分 |

### 7.2 四层架构

```
┌─────────────────────────────────────────────┐
│ ① 主智能体：成长教练（编排者）                  │
│   人格 · 语气 · 判断该进哪个模块 · 一次只问一件事  │
└──────────────┬──────────────────────────────┘
               │ 调用
┌──────────────▼──────────────────────────────┐
│ ② 技能层                                       │
│  目标设定 │ 经历挖掘 │ 价值观澄清 │ 能量分析        │
│  他人反馈 │ 测评解读 │ 画像生成 │ 行为实验          │
│  ─────── 横向：安全守护（贯穿所有对话）───────      │
└──────────────┬──────────────────────────────┘
               │ 读写
┌──────────────▼──────────────────────────────┐
│ ③ 记忆与数据层（产品核心）                        │
│  用户档案 │ 故事库 │ 线索/证据库 │ 画像版本历史      │
└──────────────┬──────────────────────────────┘
               │ 调用
┌──────────────▼──────────────────────────────┐
│ ④ 工具层                                       │
│  问卷生成与发送 │ 文件解析 │ 报告导出 │ 定时提醒      │
└─────────────────────────────────────────────┘
```

### 7.3 技能清单

**拆分原则**：工作流程、产出格式或触发时机不同就拆开；方法相同就合并。

| 技能 | 做什么 | 产出 | 触发时机 |
|---|---|---|---|
| **目标设定** | 了解用户为什么来、想解决什么 | 探索目标、当前困惑 | 第一次使用 |
| **经历挖掘** | 用 STAR 深挖故事（高光/低谷/日常三种模式） | 故事 + 线索 | 主线对话 |
| **价值观澄清** | 用取舍题和排序找出真正看重的东西 | 价值观 Top 5 | 主线对话 |
| **能量分析** | 汇总每日打卡，找出充电和耗竭的规律 | 能量模式报告 | 每周自动运行 |
| **他人反馈** | 生成问卷、发送、汇总、与自评对比 | 盲区清单 | 用户主动发起 |
| **测评解读** | 解析测评结果，与对话发现对照 | 测评线索 | 用户上传报告 |
| **画像生成** | 读取证据库，整合成画像 | 优劣势画像（带版本） | 证据够了 / 用户要求 |
| **行为实验** | 设计"本周试一试"，事后复盘 | 验证或推翻线索 | 画像生成之后 |
| **安全守护** | 识别严重情绪困扰，转介专业帮助 | 风险提示 | 始终在线 |

> 各技能的详细规格见《技能规格说明书》。

### 7.4 技能还是子智能体？

- **大部分用技能**：用户始终与同一个"教练"对话，体验连贯，上下文共享。
- **少数场景用独立子智能体**：
  - 后台重活：汇总多份反馈、生成长报告
  - **反方审核员**：画像生成后专门挑刺（如"这条结论只有一个证据""这里可能是自我美化"），对冲 AI 一味顺着用户说的问题

## 8. 核心数据设计：线索/证据库

各技能协同工作靠**统一的数据结构**：每个技能都往同一个证据库写"线索"，画像技能从中读取。

```json
{
  "线索": "擅长把复杂的事结构化",
  "类型": "优势候选",
  "证据": [
    {"来源": "经历挖掘", "内容": "大学组织200人活动，最投入前期梳理", "日期": "11-24"},
    {"来源": "他人反馈", "内容": "同事说'乱的时候找你准没错'", "日期": "12-03"},
    {"来源": "测评解读", "内容": "大五人格·尽责性 高", "日期": "12-05"}
  ],
  "置信度": "高（3个独立来源）",
  "用户确认": true
}
```

**价值**：
- **结论可追溯**：每条画像都能点开看依据
- **自动升级**：独立证据攒够后，从"候选"升级为"优势"
- **支持反驳**：用户说"不对"时，可以降级或删除

## 9. AI 人格设计

- **角色**：好奇、温和、有结构感的成长教练，不是心理咨询师
- **语气**：多提问、少说教，经常复述确认（"我理解得对吗？"）
- **原则**：
  - 一次只问一个问题
  - 回答敷衍时换个角度问，不硬逼
  - 不贴标签，不说"你就是 XX 型人格"
  - 遇到严重情绪困扰时温和提醒，推荐专业帮助

## 10. 第一版（V0.5）方案与验证标准

### 10.1 为什么是 V0.5

原定 V0 只有"经历挖掘"一种证据来源。按置信度规则，"高"需要至少 2 种来源，所以 **V0 的画像里最多只能写"可能是……"**，很难达到"说中了"的验证标准。但完整合并 V0 + V1 又会让开发量翻倍、问题难以定位。

V0.5 的思路是：**按"开发成本 × 验证价值"挑功能，而不是按版本号整版合并。**

| 内容 | 第一版是否包含 | 理由 |
|---|---|---|
| V0 全部内容 | ✅ | 核心闭环 |
| 价值观澄清 | ✅ | 纯对话即可完成，开发成本低，补上第 2 种来源 |
| 测评解读 | ✅ | 上传文件即可，开发成本低，补上第 3 种来源 |
| 结构化证据库 + 代码计算置信度 | ✅ 提前做 | 成本不高，免去数据迁移，计算更准 |
| 能量分析 | ⏸ 只做打卡收集 | 从第一天开始积累数据，周报分析到 V1 再做 |
| 他人反馈 | ⏸ 只做数据收集 | 先用普通表单手动发问卷，回复存起来，汇总解读到 V1 再做 |
| 朋友试用 | ❌ 往后放 | 先只给自己用，避开多用户和隐私问题 |

### 10.2 范围与验证标准

| 项 | 内容 |
|---|---|
| **技能** | 主智能体 + 目标设定 + 经历挖掘 + 价值观澄清 + 测评解读 + 画像生成 + 安全守护（完整技能 7 个） |
| **数据收集** | 能量每日打卡（只记录）；他人反馈回复（手动导入，只存储） |
| **证据库** | 结构化数据（每用户一份 JSON），置信度由代码按规则计算，带变更日志 |
| **用户** | 只有我自己 |
| **产出** | 一份 Markdown 或 Word 格式的个人画像 |
| **开发量** | 比原 V0 多约 30–40%，约为完整合并的一半 |
| **验证标准** | ① 读完画像有"说中了"的感觉 ② 至少发现 1 个原来没意识到的点 ③ 愿意隔几天再回来继续聊 ④ 画像中至少出现 1 条"高"置信度结论 |

### 参考执行节奏（6 周，以自己为第一个用户）

| 阶段 | 时间 | 要做的事 | 产出 |
|---|---|---|---|
| **探索期** | 第 1–2 周 | 高光/低谷回顾 + 能量日志 + 2–3 个测评 | 原始素材 |
| **反馈期** | 第 3 周 | 发出他人反馈问卷并收集回复 | 外部视角 |
| **整合期** | 第 4 周 | 交叉比对，找出多来源指向的特质 | 画像 v1 |
| **验证期** | 第 5–6 周 | 行为实验，修正画像 | 画像 v2 + 发展方向 |

**最终画像包括**：3–5 个核心优势（附证据）、2–3 个需要管理的短板、价值观 Top 5、"最佳状态说明书"。

## 11. 开发路线

| 阶段 | 做法 | 目的 |
|---|---|---|
| **V0.5** | 一个智能体 + 7 个技能（见第 10 节）；结构化证据库 + 代码计算置信度；能量打卡和他人反馈先只收集数据 | 自己用，验证对话质量和画像是否"说中" |
| **V1** | 上线能量分析（周报）和他人反馈（问卷发送 + 汇总解读），直接用 V0.5 期间攒下的数据；根据调参日志调整阈值；证据按维度衰减；补上多用户隔离与授权 | 邀请 3–5 个朋友试用 |
| **V2** | 加入反方审核、定时打卡、反馈问卷发送，做成独立应用（网页或小程序） | 做成独立产品 |

### 从"自己"到"更多人"

1. **边做边记**：哪些步骤有用、哪些浪费时间、卡在哪里
2. **提炼成工具**：把有效部分做成模板（反思问题清单、反馈问卷、画像模板）
3. **小范围试用**：先带 2–3 个朋友走一遍
4. **迭代后扩大**：再决定做成工作坊、陪伴小组、线上课程还是内容分享

> 自己的真实经历和中途的转变，会是以后帮助别人时最有说服力的部分。

## 12. 风险与应对

| 风险 | 应对 |
|---|---|
| **隐私**：内容非常私密 | 数据加密，一键删除，默认不用于训练模型 |
| **越界成心理治疗** | 明确定位为"自我探索"，内置危机识别和转介提示 |
| **AI 说什么用户都信** | 每个结论附证据，用户可以反驳和修改；引入反方审核 |
| **用户中途放弃** | 每个模块控制在 15 分钟内，做完马上给一个小发现作为奖励 |

## 13. 商业化设想（暂不急）

- **免费**：基础对话 + 简版画像
- **付费**：深度报告、他人反馈、长期追踪
- **企业 / 教练**：团队版、教练后台
