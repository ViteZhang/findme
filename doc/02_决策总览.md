## 二、关键决策

### E. 视觉风格

| # | 决策 | 结论 |
|---|---|---|
| E1 | 风格方向 | **v0.2「研究笔记」**：浅色中性灰阶，理性、精确，像一份整理好的研究资料 |
| E2 | 色彩 | 背景 `#FAFAFA`、主文字 `#171717`；唯一强调色蓝黑墨水 `#23406E`；警示红 `#B4332B` 只用于高风险安全提示 |
| E3 | 字体 | Noto Sans SC 400 / 500 + JetBrains Mono（元信息），不用衬线 |
| E4 | 签名细节 | 证据刻痕：一笔 = 一条独立证据，笔长 = 强度，空位 = 还差的一笔 |
| E5 | 备选方案 | v0.1（松石绿 + 衬线）、v0.3「灯下」（暖色深色 + 琥珀 / 雾蓝）保留存档，未采用 |
| E6 | 规范补充 1 | 危险操作按钮用主文字色实底（btn-k），红色只给高风险安全提示；优势候选的门槛条增加第 4 条「本人经历」。写在 v0.2 新增的「05 补充规则」画板，原有画板不变 |

### A. 产品形态与范围

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
| A1 | 产品形态 | **智能体 + 技能**，不是一套提示词 | 流程复杂、要跨对话积累、需要结构化产出和外部动作 |
| A2 | 技能怎么拆 | 9 个技能；高光和低谷合成一个"经历挖掘"技能，按模式区分；安全守护贯穿所有技能 | 流程、产出或触发时机不同才拆开 |
| A3 | 子智能体 | 只用于后台重活和"反方审核" | 让用户始终面对同一个教练；用反方审核来对冲 AI 一味顺着用户说的倾向 |
| A4 | 第一版范围 | **V0.5**：7 个技能完整实现；能量打卡和他人反馈先只收集数据；只给自己用 | V0 只有一种证据来源，画像里不可能出现"高"置信度的结论；把 V0 和 V1 全部合并，工作量又会翻倍 |
| A5 | 证据库 | 第一版就做成**结构化数据，置信度由代码计算** | 省掉一次数据迁移，计算结果也更稳定 |

### B. 置信度规则

| # | 决策 | 结论 |
|---|---|---|
| B1 | 来源权重 | 经历 1.0｜他人反馈 1.0｜价值观 0.8｜能量 0.8｜测评 0.5｜实验 1.2｜用户自述 0.3｜MBTI 不算证据 |
| B2 | 强度系数 | 强 1.5｜中 1.0｜弱 0.5 |
| B3 | 独立性 | 同一个故事只算 1 条证据；他人反馈每位反馈人各算 1 条；同一种测评只算 1 条 |
| B4 | "高"的门槛 | 证据数 N ≥ 3，来源种类 S ≥ 2，加权分 W+ ≥ 3.0，且反对证据加权分 W− < W+ × 0.3 |
| B5 | 优势的额外门槛 | 优势类线索要到"高"，**至少要有 1 条本人的经历证据**；没有的话最高到"中"，放进"别人眼中的你" |
| B6 | 他人未提及 | **不算反证**，只标记"他人未提及"；对方明确说出相反的情况才算反对证据 |
| B7 | 降级 | 用户否认 1 次降一级，否认 2 次归档；反对证据较多时最高只能到"中" |
| B8 | 时间衰减 | V0.5 不衰减，画像措辞中优先引用新证据；V1 按维度衰减，性格和价值观不衰减 |
| B9 | 阈值调整 | 先按现在的数值用，记录调参日志，V1 再根据日志调 |

### C. 线索管理

| # | 决策 | 结论 |
|---|---|---|
| C1 | 线索类型 | 新增"习得技能"（做得好但很消耗）和"不一致"（只用于探讨，不进画像） |
| C2 | 一条线索几种类型 | **只有一种**；同时指向两种类型时，拆成两条并标记"相关" |
| C3 | 由谁合并 | 未确认的线索由 AI 自动合并；已确认的要先问用户；生成画像前统一给用户过目 |
| C4 | 用户新建线索 | 可以，先登记为自述证据，**并当场追问一个具体例子** |
| C5 | 设计阶段补充的规则 | R1 两难题理由算价值观证据，没有理由记为弱 · R2 测评对照可跳过，不产生证据 · R3 「都重要」最多追问 2 次 · R4 打卡观察可展示但不计入 · R5 画像标题下注明「不是定论」 · R6 暂停期间不产生证据，高风险后至少隔一天恢复 · R7 测评原文件解析后询问是否删除 |

### D. 画像结构（八节）

核心优势（附习得技能）→ **别人眼中的你** → 需要管理的短板 → 价值观 Top 5 → 能量模式 → 最佳状态说明书 → 待观察 → 与上一版的变化

## 三、路线图

| 阶段 | 内容 | 用户 |
|---|---|---|
| **V0.5** | 主智能体，加上目标设定、经历挖掘、价值观澄清、测评解读、画像生成、安全守护；能量打卡和他人反馈只收集数据；反方审核先用自检清单代替 | 自己 |
| **V1** | 能量周报、他人反馈的汇总与解读；按调参日志调整阈值；按维度衰减；多用户隔离 | 3–5 个朋友 |
| **V2** | 行为实验、反方审核子智能体、定时提醒、自动发送问卷、做成独立应用 | 更多用户 |

**V0.5 的验证标准**：① 有"说中了"的感觉 ② 至少发现 1 个原来没意识到的点 ③ 愿意隔几天再回来 ④ 画像里至少有 1 条"高"置信度的结论
